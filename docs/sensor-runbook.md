## 4. Zeek Offline Replay

### 4.1 Reading a PCAP File

Zeek supports offline traffic analysis using the `-r` option, which allows it to read and analyze a previously captured PCAP file without requiring live network traffic.

```bash
zeek -r ../../2025-12-30-Lumma-Stealer-infection-with-other-malware.pcap LogAscii::use_json=T
```



### 4.2 JSON Log Configuration

The option `LogAscii::use_json=T` enables JSON-formatted output for Zeek logs.

This format makes the generated logs easier to process and integrate with other components of the ACID platform.

### 4.3 Output Location

Zeek generated the following log files successfully:

- `conn.log`
- `dns.log`
- `files.log`
- `http.log`
- `ocsp.log`
- `packet_filter.log`
- `ssl.log`
- `weird.log`
- `x509.log`

All generated logs are stored in:

```text
/home/kali/ACID-Blue1/pcap-test/offline-replay/zeek/
```



### 4.4 JSON Output Verification

The `conn.log` file contains JSON-formatted records, with each line representing a network connection.

Example fields include:

- `ts`: Event timestamp.
- `uid`: Unique connection identifier.
- `id.orig_h`: Source IP address.
- `id.resp_h`: Destination IP address.
- `proto`: Transport protocol.
- `service`: Detected application service.
- `duration`: Connection duration.

The verification confirmed that Zeek successfully generated JSON-formatted connection logs.










## 5. Suricata Offline Replay



### 5.1 Configuration Validation

Before running Suricata against the PCAP file, its configuration was tested using:

```bash
sudo suricata -T -c /etc/suricata/suricata.yaml
```
The configuration test completed successfully.
This confirms that Suricata successfully loaded the configuration file and is ready for offline PCAP analysis.




### 5.2 EVE JSON Configuration

Suricata uses the EVE JSON logging system to generate structured event logs.

The configuration file is located at:

```text
/etc/suricata/suricata.yaml
```

The configured EVE output filename is:

```yaml
filename: eve.json
```

This setting specifies the name of the JSON event log file generated by Suricata.
The EVE logging configuration was verified and found to be enabled.

The relevant settings in `suricata.yaml` are:

```yaml
- eve-log:
    enabled: yes
    filetype: regular
    filename: eve.json
```

- `enabled: yes` enables EVE logging.
- `filetype: regular` writes events to a regular file.
- `filename: eve.json` defines the output filename.

No configuration changes were required.

The output directory is controlled separately using the `-l` command-line option during execution.




### 5.3 Offline PCAP Replay

Suricata was executed in offline mode using the same PCAP file used by Zeek.

The following command was executed from the Suricata output directory:

```bash
sudo suricata -r ../../2025-12-30-Lumma-Stealer-infection-with-other-malware.pcap -c /etc/suricata/suricata.yaml -l .
```

Command options:

- `-r`: Reads a previously captured PCAP file.
- `-c`: Specifies the Suricata configuration file.
- `-l`: Specifies the output directory.
